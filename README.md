# food-management-project

Project Description: 
One persistent problem of households related to sustainability is food waste. 
Households struggle to keep up with expiration dates of products, what ingredients they have on-hand and even how to include them into their cooking, thus leading to throwing away perfectly usable items. 
My proposition to solve this issue is to create a shared fridge and recipe management system. 
Moreover, by using this system both individuals and households will be able to track all of their inventory and explore new recipes.
